<!-- Script localStorage (vanilla JS — per prototipo HTML) -->
<script>
  const toggle = document.getElementById('themeToggle');
  const root   = document.documentElement;
  const saved  = localStorage.getItem('vtn-theme') || 'light';
  root.setAttribute('data-theme', saved);
  toggle.addEventListener('click', () => {
    const next = root.getAttribute('data-theme') === 'light' ? 'dark' : 'light';
    root.setAttribute('data-theme', next);
    localStorage.setItem('vtn-theme', next);
  });
</script>

⚠️ accent-orange in dark mode: anche se il contrasto AA è tecnicamente sufficiente per testi grandi, accent-orange è definito dal DS come colore di sfondo (badge, allergen box) — non come colore testo. Usarlo come testo in dark romperebbe la coerenza semantica del sistema.

Recolorazione SVG inline — CSS filter

Le icone delle SectionCard sono SVG inline con colori hardcoded (fill="#460112", stroke="#460112"). Il CSS non può sovrascrivere attributi inline con la normale cascata. La soluzione adottata è un CSS filter applicato all'elemento <svg>: converte qualsiasi colore scuro → panna #ffedd7. 

/* Dark mode — recolorazione SVG inline */
[data-theme="dark"] .section-card__icon svg,
[data-theme="dark"] .menu-header__logo svg {
  filter: brightness(0) saturate(100%) invert(97%)
          sepia(10%) saturate(300%) hue-rotate(320deg)
          brightness(103%) contrast(97%);
  transition: filter 0.35s ease;
}

/* Light mode — nessun filtro */
[data-theme="light"] .section-card__icon svg,
[data-theme="light"] .menu-header__logo svg {
  filter: none;
}

Come funziona: brightness(0) azzera tutti i canali colore → nero puro. invert(97%) lo porta a quasi-bianco. sepia + hue-rotate + saturate lo spingono verso la tonalità calda della panna #ffedd7. Il filtro va applicato sul tag <svg>, non sul contenitore.

Implementazione JavaScript
// Vanilla JS (prototipo HTML)
const toggle = document.getElementById('themeToggle');
const root   = document.documentElement;

// Ripristina preferenza salvata (default: 'light')
const saved = localStorage.getItem('vtn-theme') || 'light';
root.setAttribute('data-theme', saved);

toggle.addEventListener('click', () => {
  const next = root.getAttribute('data-theme') === 'light' ? 'dark' : 'light';
  root.setAttribute('data-theme', next);
  localStorage.setItem('vtn-theme', next);
});

// React hook equivalente (Next.js)
function useTheme() {
  const [theme, setTheme] = useState<'light' | 'dark'>(() =>
    (localStorage.getItem('vtn-theme') as 'light' | 'dark') || 'light'
  );
  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('vtn-theme', theme);
  }, [theme]);
  return { theme, toggle: () => setTheme(t => t === 'light' ? 'dark' : 'light') };
}
